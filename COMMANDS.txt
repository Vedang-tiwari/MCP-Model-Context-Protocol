================================================================================
          MCP: AUTONOMOUS JOB SCOUT & APPLICATION AGENT - COMMAND GUIDE
================================================================================

1. VIRTUAL ENVIRONMENT ACTIVATION
--------------------------------------------------------------------------------
Before executing any Python or CLI commands, activate the project environment:

Windows (PowerShell):
  .\venv\Scripts\Activate.ps1

Windows (Command Prompt / CMD):
  .\venv\Scripts\activate.bat

Linux / macOS:
  source venv/bin/activate


2. LOCAL WEB DASHBOARD & HOSTING
--------------------------------------------------------------------------------
Launch the local web dashboard (Paper-and-Obsidian design interface):

Default host & port (http://127.0.0.1:8000):
  python cli.py web

Custom host and port:
  python cli.py web --port 8080
  python cli.py web --host 0.0.0.0 --port 8000

Accessible Web URLs:
  Web Interface:           http://localhost:8000
  Live Stats API:          http://localhost:8000/api/stats
  Jobs Feed API:           http://localhost:8000/api/jobs
  Resume Matrix API:       http://localhost:8000/api/resumes
  Registered Platform API: http://localhost:8000/api/platforms
  System Info API:         http://localhost:8000/api/system


3. RESUME MATRIX & ROLE-TAILORED MAPPING
--------------------------------------------------------------------------------
Upload and map specific resumes to job roles (e.g. AI Engineer, SWE, FDE).
The agent dynamically attaches the exact matching resume during applications.

List all configured resumes:
  python cli.py resume list

Upload and map a resume to an AI Engineer role:
  python cli.py resume upload --file "C:\path\to\ai_resume.pdf" --role "AI Engineer"

Upload and map a resume to SWE and set it as the default fallback:
  python cli.py resume upload --file "C:\path\to\swe_resume.pdf" --role "SWE" --default

Upload and map a resume for Forward Deployed / Frontend (FDE):
  python cli.py resume upload --file "C:\path\to\fde_resume.pdf" --role "FDE"

Simulate & test which resume will be selected for a specific job title:
  python cli.py resume test "Senior Generative AI Research Engineer"
  python cli.py resume test "Software Development Engineer (SWE)"
  python cli.py resume test "Forward Deployed Engineer - Full Stack"
  python cli.py resume test "Engineering Manager"

Delete a resume mapping by its ID or role pattern:
  python cli.py resume delete res_ai
  python cli.py resume delete "AI Engineer"


4. JOB DISCOVERY & REAL-TIME SCOUTING
--------------------------------------------------------------------------------
Sweep 12+ career platforms (Greenhouse, Lever, LinkedIn, Indeed, Wellfound,
RemoteOK, Remotive, Arbeitnow, Internshala, Jobicy, WeWorkRemotely, etc.):

Run instant discovery sweep using target roles in search_preferences.json:
  python cli.py scout

Override target roles for a specific sweep:
  python cli.py scout -r "AI Engineer" -r "Full Stack Developer"
  python cli.py scout -r "Python Developer" -r "Backend Engineer"

Limit sweep to jobs posted within the last N hours:
  python cli.py scout --age 12
  python cli.py scout -r "Software Engineer" -a 6


5. LISTING DISCOVERED JOBS & DATABASE QUERIES
--------------------------------------------------------------------------------
Query and inspect jobs stored in data/mcp_jobs.db:

List recent 20 discovered jobs:
  python cli.py list

List top 50 jobs with minimum candidate match score (e.g. >= 70%):
  python cli.py list --limit 50 --min-score 70

Filter jobs by platform:
  python cli.py list --platform wellfound
  python cli.py list --platform remoteok
  python cli.py list --platform ats_direct
  python cli.py list --platform linkedin
  python cli.py list --platform indeed
  python cli.py list --platform remotive
  python cli.py list --platform arbeitnow

Filter jobs by status:
  python cli.py list --status DISCOVERED
  python cli.py list --status EVALUATED
  python cli.py list --status QUEUED
  python cli.py list --status APPLIED
  python cli.py list --status MANUAL_REVIEW


6. CANDIDATE FIT EVALUATION
--------------------------------------------------------------------------------
Run algorithmic scoring (0-100) and criteria breakdown against candidate profile:

Evaluate a job by its unique ID (or short ID):
  python cli.py evaluate <JOB_ID>

Example:
  python cli.py evaluate 4829776


7. AUTONOMOUS APPLICATION WORKFLOW
--------------------------------------------------------------------------------
Launch Playwright stealth browser to fill application fields, attach matching
tailored resume, solve ATS screening questions via LLM, and take screenshot evidence:

Pre-fill form and stop at final review screen for human check:
  python cli.py apply <JOB_ID>

End-to-end automated submission (clicks final submit button):
  python cli.py apply <JOB_ID> --auto-submit


8. PLATFORM REGISTRY MANAGEMENT
--------------------------------------------------------------------------------
Add, toggle, or remove custom job boards, RSS feeds, JSON APIs, and scrapers:

List all registered platforms and active status:
  python cli.py platform list

Add a new custom RSS job board:
  python cli.py platform add -n "techjobs" -t "rss" -u "https://example.com/feed.rss" -d "Tech Jobs RSS"

Add a new custom REST JSON API:
  python cli.py platform add -n "startupjobs" -t "json_api" -u "https://api.example.com/jobs?tag={role}" -d "Startup Jobs API"

Enable or disable a specific platform:
  python cli.py platform toggle indeed --disable
  python cli.py platform toggle indeed --enable
  python cli.py platform toggle wellfound --disable

Remove a custom registered platform:
  python cli.py platform remove techjobs


9. 24/7/365 CONTINUOUS BACKGROUND WORKER
--------------------------------------------------------------------------------
Run autonomous background daemon that periodically discovers, scores, and applies:

Start background worker:
  python cli.py worker


10. NATURAL LANGUAGE AGENTIC ORCHESTRATOR
--------------------------------------------------------------------------------
Run autonomous multi-turn tool-calling agent using open-source models (Ollama/Groq):

Run agent with a natural language task:
  python cli.py agent "Find high-match AI Engineer jobs on Wellfound and show their scores"
  python cli.py agent "Evaluate the top 5 highest matching Software Engineer jobs in the database"


11. METRICS & APPLICATION STATS
--------------------------------------------------------------------------------
Display summary metrics in terminal:

View metrics dashboard:
  python cli.py stats


12. MODEL CONTEXT PROTOCOL (MCP) SERVER
--------------------------------------------------------------------------------
Expose MCP tools to external LLM clients (Claude Desktop, Cursor, Antigravity):

Standard I/O transport (stdio):
  python cli.py mcp --transport stdio

Server-Sent Events HTTP transport (SSE):
  python cli.py mcp --transport sse


13. AUTOMATED TEST SUITE
--------------------------------------------------------------------------------
Execute unit and integration tests:

Run all 15 tests across the entire project:
  python -m unittest discover -s tests -p "test_*.py" -v

Run resume matrix tests:
  python -m unittest tests/test_resumes.py -v

Run web dashboard API tests:
  python -m unittest tests/test_web.py -v

Run core components tests:
  python -m unittest tests/test_components.py -v
